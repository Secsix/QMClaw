## 1. 背景

夜班标定会在 DataVault 里留下成百上千条测量记录（一次会话可含数百条、覆盖多个比特与多类实验）。
人工翻看这些记录判断"哪个比特是活的、活的时候该设成什么参数"非常耗时，且容易看错。

本需求要一个**离线**的批量体检工具：把一整段序号区间的 DataVault 数据读进来，
按比特汇总单比特性质，并按用户给定的口径判活，最后给出**可以直接写回 LabRAD 的参数**。

## 2. 目标

1. 一条命令给出"这段数据里哪些比特是活的、参数是什么"。
2. 判活口径由用户定义，工具负责把口径**量化、可复现**地落到具体数值上。
3. 输出的参数能直接用于 `qubit.regs.xxx = value` 赋值，不做二次换算。
4. 完全离线：不连 LabRAD、不动硬件寄存器、不启停任何服务。

## 3. 名词与数据约定

| 名词 | 含义 |
|---|---|
| 会话（session） | 一个 DataVault 目录，如 `D:\DataVault\LQHL.dir\test.dir\20260822_device1.dir` |
| 数据集（dataset） | 一个 `.hdf5` 文件，文件名 `"03649 - q21_5%c IQraw.hdf5"` = 序号 / 比特名 / 实验名 |
| 工作点（working point） | 该比特被判为活的那一刻的寄存器状态（`f10` / `zpa` / `fread` 等） |
| zpa | 比特直流偏置电压，**等于寄存器 `bias_z`**（见 §6 R5-2） |

实验类型（文件名末尾）：`IQraw` / `PiPulse` / `PiPulse df` / `Ramsey df` / `Spectroscopy` / `S21_dis`。

## 5. 详细需求点

### R1 按会话目录 + 序号区间定位数据

- **输入**：`--vault <会话目录>`、`--start <起始序号>`、`--end <结束序号>`（闭区间，均可省略）
- **行为**：遍历目录下 `*.hdf5`，按文件名解析出 `序号 / 比特名 / 实验名`，过滤序号区间
- **验收**：本次会话区间 3648–4455 读到 **808** 个数据集、**8** 个比特
  （q13_15、q15_13、q17_11、q19_9、q21_5、q21_7、q7_21、q9_19）

### R2 解析 HDF5 与 LabRAD 参数快照

- **列名**：`Independent<i>.label` 为自变量，`Dependent<i>.label` 为因变量，按序拼成列
- **参数快照**：HDF5 属性 `Param.<名字>`，值为 `data:application/labrad;base64,...`
  的 tagged data，解码规则：

  | tag | 类型 | 载荷布局 |
  |---|---|---|
  | `v` | float64 | `[4B 头][1B 'v'][6B][8B 大端 float64]` → 值在**偏移 11** 处 |
  | `i` | int32 | 值在偏移 9 |
  | `s` | string | 值在偏移 13 |
  | `*` | complex | 偏移 13 起两个 int32 |

- **注意**：base64 必须用 `urlsafe_b64decode`（含 `_`），否则解码报
  "number of data characters (25)" 之类错误
- **验收**：`PiGate.amp` 与 `PiHalf.amp` 恰好为 2:1 关系（2.39674 / 1.19837）→ 大端序正确

### R3 计算单比特性质指标

| 实验 | 指标 | 定义 |
|---|---|---|
| IQraw | `sep` | \|z₁−z₀\|，两态 IQ 云团中心距离（ADC counts） |
| | `snr` | sep / √((σ₀²+σ₁²)/2) ← **判活主指标** |
| | `norm` | sep / (\|z₀\|+\|z₁\|) 归一化分离度 ← 辅助指标 |
| | `fidelity` | 沿 (m₁−m₀) 方向的最优单发判别正确率 |
| PiPulse | `swing` | P1(piAmp) 峰谷落差 |
| | `amp_opt` | 峰值处对应的 pi 幅度 |
| | `sigma` | 噪声（见 R4-2） |
| Ramsey df | `T2*` | 1/√((1/T₂)² + (π·df)²) |
| | `T2` | 阻尼包络时间常数 |
| | `detune_MHz` | 振荡频率的一半 |
| Spectroscopy | `f10_meas` | P1(freq) 共振峰（抛物线细化） |
| S21_dis | `fread_meas` | \|0> 态幅度谷 |
| | `distance01_max` | \|0>/\|1> 在 IQ 平面的最大距离（读出分辨率） |

### R4 按用户口径判活

用户口径原文：**"iqraw 大于 0.1，piamp 实验正常"**。工具负责把它量化：

**R4-1　IQraw > 0.1**
- 主判据：`snr > 0.1`；同时报告 `norm`，两者结论一致时判据稳健
- 辅助参考：`norm > 0.1` 在本批数据上给出**同一批**候选比特

**R4-2　PiAmp 实验正常**
- P1(piAmp) 出现**完整 Rabi 振荡**，判据（三条同时满足）：
  1. 存在内部极大值（峰），且峰后有回落（谷不在数据末端）
  2. 峰谷落差 `swing ≥ 0.15`
  3. `swing ≥ 4σ`，σ 由三阶差分 MAD 估计（三阶差分对光滑曲线趋 0，只剩噪声）
- **为什么不用拟合判据**：噪声数据的 5 参数阻尼余弦拟合会发散，实测曾算出
  "对比度 292 / 1120" 的荒谬值；模型无关判据稳定且可解释
- 阈值集中在 `metrics.py::RABI_SWING_THRESH` / `RABI_SIGMA_K` 与
  `health_report.py::IQRAW_THRESH`，可改

**R4-3　总判定**：`alive = IQraw 通过 AND PiAmp 正常`

### R5 提取活比特的工作点参数

**R5-1　工作点的定义**
- 寄存器快照是**测量时刻**的值；夜班标定是在 `(f10, zpa)` 网格上扫描的，
  寄存器里的 f10 是**当时被扫描的值**（含 −201 GHz、225 GHz 这类越界值），
  zpa 也是从 1.0 扫到 3.0
- 因此工作点 = **判活那条记录**的寄存器快照；其余实验（Ramsey / 谱扫 / S21）
  按与工作点最近的文件对齐后再算指标

**R5-2　zpa 的来源**
- **zpa = `regs.bias_z`**（比特直流偏置）。依据仓库既有写法
  `measure_scripts/measure_scripts/sq_workflow/backend.py:530`：
  `sq.t1(qobj, zpa=qobj.regs.bias_z, ...)`
- 数据里**没有**独立的 `zpa` 寄存器；`PiGate.zpa` / `PiHalf.zpa` 是单次 π 脉冲的 z 偏置
  （本批全为 0），不是比特直流偏置，不可混用

**R5-3　输出四项参数**
- `zpa`（= bias_z）、`f10`、`f21`、`fread`，单位 GHz（zpa 为 V）
- 附带 `fc`、`fc_read`、`PiGate.amp`、`PiHalf.amp`、`PiGate.length`、`ReadIn.power`
- 报告第四节直接给出可粘贴的赋值代码

**R5-4　异常寄存器修正**
- 个别文件 `fread` 被误写成 182 GHz → 判为越界，改用会话中位数并标注
- 越界判定区间 0.1–100 GHz

### R6 输出报告

- `qubit_health.csv`：每比特一行，全部指标
- `qubit_health.md`：四个小节 —— 判活口径 / 判活结论 / 活比特参数明细 / 单比特性质汇总 /
  可写入 LabRAD 的参数
- 报告须写明数据源、序号区间、生成时间、判活口径定义（可自证）

### R7 离线、只读、无副作用

- 只依赖 `h5py` + `numpy` + `scipy`，不 import 任何 LabRAD/服务模块
- 不写 DataVault、不改硬件寄存器、不启停服务
- 单次全量 808 文件耗时 **2.8 s**（带文件级缓存）

### R8 可复用

- 命令行换目录/区间即可复用，无需改代码
- 自检用例覆盖解码往返、指标行为（`python test_health_report.py` → 9/9 PASS）

### 例子 2　q13_15 的完整判定过程（活）

**(a) IQraw（文件序号 4202，3000 发）**

| 量 | 数值 |
|---|---|
| \|z₀\| / \|z₁\| | 1 912 513 / 1 926 557 |
| sep = \|z₁−z₀\| | 2 063 718 |
| σ₀ / σ₁ | 339 310 / 774 922 |
| **snr** | 2 063 718 / √((339310²+774922²)/2) = **3.450** > 0.1 ✅ |
| norm | 2 063 718 / (1 912 513+1 926 557) = **0.538** |
| fidelity | **0.9985** |

**(b) PiAmp（文件序号 4203，piAmp 0→3 步进 0.2，16 点）**

```
P1 = [0.010 0.063 0.157 0.350 0.470 0.610 0.620 0.533
      0.447 0.287 0.163 0.070 0.083 0.067 0.123 0.160]
                  ↑峰(idx6)          ↑谷(idx12)
```
- 峰谷落差 = 0.620 − 0.070 = **0.537 ≥ 0.15** ✅
- 噪声 σ = 0.0232（三阶差分 MAD），显著性 = 0.537 / 0.0232 = **23.1 ≥ 4** ✅
- 最优 pi 幅度 **amp_opt = 1.2**（0.2 步进，落在扫描范围内）

**(c) 寄存器快照（该比特工作点，序号 4202/4203 记录一致）**


## 8. 边界情况与已知限制

| # | 情况 | 处理 |
|---|---|---|
| 1 | 寄存器 f10 是扫描值，含大量越界值 | 参数只取工作点记录；报告中明确说明 |
| 2 | 个别文件 fread 被误写（182 GHz） | 越界判定 0.1–100 GHz，改用会话中位数并留痕 |
| 3 | Ramsey 延迟窗口仅 0–1000 ns | T2 ≥ 1 µs 时 T2 只是下界，报告中注明 |
| 4 | 谱扫未落在工作点 f10 附近 | 取最显著的一条并标 ⚠（表示未获得干净共振，如 q21_5） |
| 5 | 噪声数据 Rabi 拟合发散 | 改用模型无关判据（R4-2） |
| 6 | Ramsey 拟合退化到错误频率 | FFT 主频初始化 + 频率边界约束；不成立标"未测得" |
| 7 | 未与 LabRAD 在线数据交叉校验 | `DataLab` 离线不可用（交互式 `set_vault_path()` 会 EOFError），本次为纯离线结论 |
| 8 | 判活阈值写死在代码里 | 集中在两个文件的顶部常量，改阈值不需改逻辑 |
